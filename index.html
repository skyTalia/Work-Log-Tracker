Help

Quick notes.

How it works

QURI tracks tasks and hours by month. Pick a month, then type tasks and hours for each weekday — everything saves as you type.

HTP tracks hours only for a custom billing period. Set the start and end dates and click Apply. Each weekday starts at 4.00 hours.

Invoices follow the HealthTek invoice layout. Fill in Settings → Invoice details once, then enter the invoice number on the HTP page and click Generate PDF. Generated invoices are downloaded, not stored.

Reports show earnings for all trackers, QURI only, or HTP only. PHP values use the current exchange rate.
